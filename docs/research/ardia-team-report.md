# Ardia 專案背景摘要（調查日 2026-10-23）

範圍：只看專案本身的公開資訊（repo、官網、release notes），不涉及維護者個人背景。標記說明：【證】有來源佐證；【推】推測。

## 結論

Ardia 看起來是「單人開發、AI 輔助、極高速迭代、年資很短」的專案。沒有找到詐欺或惡意的證據，授權與原始碼公開程度比一般新專案透明；但可信度的依據幾乎全是維護者自己發布的資料。

最大的不確定性有三個：
1. 單一維護者佔絕大多數 commit，沒有公司、資金或安全流程的公開說明，長期維護與 bus factor 風險高。
2. 專案極新且變動劇烈（短時間內改名、換引擎兩次、每天多個 release），沒有第三方評論或安全審計。
3. 瀏覽器會經手密碼與登入狀態，而快速節奏代表程式碼多半未經充分外部審視（近期 commit 全帶 Claude 共同作者標記）。

結論是「可試用、不建議在沒有備案的情況下當唯一主力」；若要用，建議先觀察幾個月，或選擇 stable 版而非 nightly。

## 1. 專案歷史與活躍度

- 【證】公開 commit 歷史只有約 1 個月（repo 建立日與首個 commit 有落差，原因不明）；原名 Netnyahoo，0.2.33（2026-10-12）改名 Ardia。
- 【證】Release 節奏：stable 約 3.5 週 33 個版本，另有每天數次的 nightly；版本號停在 0.2.x。
- 【證】引擎演進：CEF → 自製 ArdiaCore → 純 Chromium → 0.2.40-nightly.5 改用 Helium 的隱私 patches。
- 【證】Star 數在最近一兩週內暴增，issue/PR 一天湧入約 40 筆，多為外部使用者的功能請求與 PR。
- 【證】repo 內有 `.claude/`、`CLAUDE.md`、`AGENTS.md`，最近 100 個 commit 全部帶 Claude 共同作者；另有以「增加 Mac 下載量」為目標的成長實驗日誌（`docs/growth.md`），屬行銷導向紀錄，非惡意。

## 2. 資金與營運

- 【證】官網稱免費，未提資金，找不到贊助、募資或公司實體。
- 【證】基礎設施：自建網站分析、自動更新（Sparkle）、Apple 公證；固定成本由誰負擔未說明。
- 【推】商業模式不明。
- 風險：單人專案 + 無資金說明，長期維護沒有保證。專案為 GPL-3.0，停更時他人可 fork，但需要 Chromium 持續安全更新的瀏覽器，停更本身就是安全問題。

## 3. 外部評價

- 【證】搜尋沒有找到 Hacker News、Reddit、媒體的獨立討論或評測，也沒有針對安全、抄襲、隱私的質疑；這只代表搜尋工具沒收錄，不代表沒有。
- 【證】官網「8 倍效能」宣稱只比冷啟動、使用 nightly 版、由作者自測，屬自報未獨立驗證；對 Helium 只快 26%，且官網自己揭露 Helium 在分頁切換等項目勝出，這點誠實。
- 【證】Issue 區有真實使用者回報 bug，維護者與外部貢獻者都有動作。

## 4. 與其他專案的關係

- 【證】Helium（GPL-3.0）：0.2.40-nightly.5 起引擎以 Helium 的 patch 系列為基礎；NOTICE 宣告整體發布版本為 GPL-3.0，Ardia 自己的原始檔另以 Apache-2.0 授權。
- 【證】NOTICE 另列 Chromium、ungoogled-chromium、CEF、uBlock Origin、Sparkle、bang 清單、React Native macOS。
- 【證】與 Dia、Arc：官網聲明不隸屬 Google 或 The Browser Company；產品是仿效，非衍生程式碼。
- 注意：引擎基礎在最近一週內才換成 Helium，隱私與安全補丁的基準尚未經過時間檢驗。【推】

## 5. 風險與正面訊號

風險訊號
- 單人主導，無公司、無資金說明、無聯絡安全問題的管道（查不到 `SECURITY.md`）。
- 專案年資極短，發版與 nightly 過快，AI 協作 commit 的審查深度未知。
- 成長導向行銷，並有網站分析資料收集；App 內遙測有揭露（崩潰回報選擇加入，另有每次啟動讀取 `ardia.dev/switches.json` 的 kill-switch 請求，文件稱無 cookie、無 ID），屬自述，程式碼層面的驗證見 `ardia-audit-report.md`。
- 最後幾天外部 PR 暴增，其中有機器人帳號開的 PR，應留意供應鏈（誰能合併、是否有雙人審查）。【推】

正面訊號
- GPL-3.0 與 NOTICE 完整，會承認上游並在官網揭露對手較勝之處。
- 原始碼公開、release 附原始碼說明、Apple 公證。
- 安全修補有跡可循（Touch ID 保護已儲存密碼、預設關閉 AppleScript 執行頁面 JS、封鎖外洩的中繼憑證）。
- 有真實外部使用者與貢獻者活動。

- 8 倍宣稱的獨立重現。
